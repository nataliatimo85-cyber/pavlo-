# APOGEE — Космічна програма

Ігровий браузерний 3D-прототип космічного симулятора з українським інтерфейсом. Створи ракету, запусти її, вийди на орбіту та спробуй EVA.

## Грати в браузері через GitHub Pages

Гра готова до статичної публікації: усі ресурси локальні та мають відносні шляхи, а файл `.nojekyll` вимикає обробку Jekyll.

Власнику репозиторію потрібно один раз відкрити **[Settings → Pages](https://github.com/nataliatimo85-cyber/pavlo-/settings/pages)** та встановити:

1. **Source:** Deploy from a branch.
2. **Branch:** `codex/apogee-3d`.
3. **Folder:** `/ (root)`.
4. Натиснути **Save**.

Після успішного розгортання в Pages гра буде доступна за адресою **https://nataliatimo85-cyber.github.io/pavlo-/**. До увімкнення Pages ця адреса ще не працює. Завантажувати файли або запускати Python для онлайн-версії не потрібно.

## Запуск

Потрібні сучасний браузер із WebGL та Python 3. Жодних бібліотек, npm-пакетів, API-ключів чи зовнішніх ресурсів гра не завантажує.

```sh
git clone --branch codex/apogee-3d --single-branch https://github.com/nataliatimo85-cyber/pavlo-.git
cd pavlo-
python3 -m http.server 8080
```

Відкрий **http://localhost:8080**. На Windows можна використати `py -m http.server 8080`. За наявності Node.js команда `npm start` запускає той самий Python-сервер. Відкривати `index.html` через `file://` не слід: браузер блокує ES-модулі.

Для статичного хостингу достатньо п'яти файлів: `index.html`, `style.css`, `game.js`, `physics.js`, `renderer.js`. Серверна частина не потрібна. Публічний сайт автоматично не розгортається.

## Що працює у v0.1

- Власний WebGL-рендерер, повна 3D-сцена та вільне обертання камери в ангарі, польоті й на карті.
- Ангар: 18 типів деталей у п'яти категоріях, вертикальне модульне складання, перестановка, копіювання, видалення, вибір зі списку або натисканням на ракету.
- Регулювання довжини й діаметра баків; маса та місткість змінюються разом із розмірами. Чотири процедурні покриття.
- Атмосферні, вакуумні, твердопаливні та іонні двигуни з різними тягою й питомим імпульсом. SRB після запуску не вимикається дроселем.
- Рідинні баки умовно об'єднують паливо й окисник. Присутній окремий модуль бака RCS.
- Два ступені в готовій ракеті, відділення нижньої групи, скидання обтічників, розкладання опор, панелей, драбин і дверей вантажних відсіків.
- Гравітація центрального тіла, опір експоненційної атмосфери, витрата палива, змінна маса, зіткнення й нагрівання з урахуванням теплового щита.
- Напівкроковий інтегратор velocity Verlet із кроком 0,05 с, телеметрія Ap/Pe, швидкість, вертикальна швидкість та оцінка ΔV.
- SAS: утримання, проград, ретроград, радіальний напрям і ручне керування.
- 3D-карта з прогнозом траєкторії та виходу з гравітаційного поля, попереднім переглядом проградного маневру, навчальною ціллю й показниками відстані / відносної швидкості.
- Прискорення часу 1×, 5×, 20×, 100× поза атмосферою без тяги та EVA.
- Земля, Марс, Венера й Місяць із різними гравітацією, атмосферою та процедурним забарвленням. Вибір тіла починає окремий політ.
- Космонавт із простих 3D-форм, EVA-ранець, запас палива EVA, ходьба по поверхні, стрибок, повернення в капсулу поблизу та встановлення українського прапора.
- Простий вихлоп, індикація нагрівання, процедурні пагорби й синтезований звук двигуна та механізмів.
- Збереження ракети в браузері, імпорт / експорт JSON, імпорт власної планети; адаптивний інтерфейс і сенсорна камера / кнопки напряму.

## Фізична модель та межі прототипу

Планети зменшено приблизно до масштабу 1:10; вони не відповідають реальним радіусам Землі чи часу польоту. Гравітація залежить від відстані за законом обернених квадратів, орбіти обчислюються з енергії й моменту імпульсу. Це модель двох тіл з однією активною планетою, без взаємодії між планетами, обертання атмосфери, припливів та patched conics. Назви планет позначають стилізовані навчальні тіла.

Прогноз орбіти — балістичний: без тяги й атмосфери. Маневр показує наслідок миттєвого проградного ΔV через заданий час, відрахований від поточного моменту; автоматичного виконання немає. Ціль — кінематичний навчальний маркер на круговій орбіті, без фізичного стикування. ΔV — оцінка у вакуумі без втрат.

Поки що не реалізовані: інтер'єри кораблів, ремонт, стикування, міжпланетні перельоти, окремі потоки окисника, електромережа, аеродинамічна підйомна сила, анімація вектора тяги, відрив окремих деталей від нагрівання, повноцінні абляція й анімації астронавта, об'ємні хмари, рефракція, складний рельєф, дим / пил, просторова акустика та радіопереговори. Панелі, вузол стикування, гіроскоп і бак RCS у цій версії переважно візуальні; SAS доступний будь-якому керованому кораблю, EVA має власний запас палива. На поверхні використовується локальна плоска зона з пагорбами біля старту. Вихлоп — проста геометрія без фізичної моделі shock diamonds.

## Моди

Через **«Імпорт / мод»** в ангарі можна завантажити ракету або JSON планети. Приклад: [mods/example-planet.json](mods/example-planet.json). Після імпорту планета з'являється на карті. Для нового типу деталі додай запис у `PARTS` у `physics.js` і геометрію у `drawShip` у `game.js`. Довільний виконуваний код через JSON не завантажується.

## Перевірки

Потрібен Node.js 22+:

```sh
npm test
```

П'ять тестів перевіряють збереження енергії на круговій орбіті, траєкторію втечі, падіння суборбітальної траєкторії, тягоозброєність / ΔV базової ракети й валідацію імпорту. Також виконано браузерну перевірку Chromium: ангар, збереження, запуск, витрата палива, карта, прогноз маневру, EVA, повернення в капсулу, відділення ступеня та мобільний макет.

## Файли

- `physics.js` — незалежна від браузера математика, характеристики деталей та валідація.
- `renderer.js` — WebGL, геометрія, камера, освітлення та процедурне покриття планет.
- `game.js` — симуляція, сцени, будівництво, керування та збереження.
- `index.html`, `style.css` — український інтерфейс.
